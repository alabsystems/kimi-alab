# kimi-alab

ALab harness that runs unmodified Kimi Code CLI from the atpkg store and moves running sessions onto newer builds.

kimi-alab is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries kimi-alab's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install kimi-alab
```

Every release is listed under [Releases](https://github.com/alabsystems/kimi-alab/releases),
and its notes are in `release-notes/`.

## Security

Report a security problem privately to hello@alab.systems, not in a public
issue.
